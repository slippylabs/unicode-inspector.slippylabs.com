UNICODE INSPECTOR

Paste anything that is not behaving — a filename that will not match, a password that will not compare, a domain that looks right. This shows you every codepoint in it, and calls out the ones you cannot see.

Cleaned text

Normalization decides whether é is one codepoint or two, and whether ﬁ counts as fi. NFC is what you almost always want to store. NFKC also folds compatibility characters, which is what makes it useful for comparing user input — and lossy for round-tripping it.

Character names are carried for the ranges this tool exists to diagnose — Latin, Greek, Cyrillic, Hebrew, Arabic, punctuation, fullwidth forms, variation selectors and the mathematical alphabets. Outside those, the block, category and script are still exact; they come from the browser's own Unicode tables rather than from a list shipped here.
